# Controles

El juego detecta automáticamente el dispositivo en uso (teclado y ratón, mando de Xbox o mando de PlayStation) y las ayudas en pantalla cambian solas. También se muestran en **Pausa → CONTROLES**.

## Teclado y ratón

| Acción | Control |
|---|---|
| Mover | `W` `A` `S` `D` |
| Correr | Pulsar `W` dos veces seguidas (doble toque, 300 ms) |
| Agacharse / levantarse | `Shift` izquierdo |
| Deslizarse | `Shift` izquierdo mientras corres |
| Saltar | `Espacio` |
| Mover la cámara | Ratón |
| Entrar / salir del modo captura (apuntar) | Clic derecho |
| Lanzar Pokéball (en modo captura) | Clic izquierdo |
| Cambiar de Pokéball (en modo captura) | `Q` / `E` o rueda del ratón |
| Fijar objetivo / cambiar al siguiente | `Tab` (pulsación corta) |
| Soltar el objetivo | `Tab` mantenido (400 ms) |
| Interactuar (abrir cofres, talar, picar) | `F` |
| Pausa / salir del modo captura | `Esc` |

## Mando

Los botones se asignan por posición, por lo que equivalen en cualquier mando.

| Acción | Xbox | PlayStation |
|---|---|---|
| Mover | Stick izquierdo | Stick izquierdo |
| Correr | Pulsar stick izquierdo (L3) | L3 |
| Cámara | Stick derecho | Stick derecho |
| Saltar | A | ✕ |
| Agacharse / deslizarse | B | ○ |
| Interactuar | X | □ |
| Apuntar (modo captura, mantenido) | LT | L2 |
| Lanzar Pokéball | RT | R2 |
| Pokéball anterior | LB | L1 |
| Pokéball siguiente | RB | R1 |
| Fijar / cambiar objetivo | Pulsar stick derecho (R3) | R3 |
| Soltar objetivo | R3 mantenido (400 ms) | R3 mantenido |
| Pausa | Menú | Options |

**Menús con mando:** stick izquierdo o cruceta para moverse, botón inferior (A / ✕) para aceptar, botón derecho (B / ○) para volver.

## Notas

- El modo captura se activa con el clic derecho (se mantiene hasta volver a pulsarlo o pulsar `Esc`) o, con mando, mientras se mantiene L2 / LT.
- Mientras apuntas, el personaje se mueve siempre respecto a la cámara.
- Fuera del modo captura, girar la cámara **no** desvía el rumbo del personaje mientras mantienes la dirección.
- La cruceta del mando no tiene acción en el juego (solo navega los menús).
- Mandos soportados: Xbox 360 / One / Series y emuladores XInput (Steam Input, DS4Windows), DualShock 4 y DualSense (USB y Bluetooth).
- Al perder el foco de la ventana, el juego se pausa automáticamente.
